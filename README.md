# Forge OS Homebrew Tap

Homebrew formulae for [Forge OS](https://github.com/modib/forge) — an AI-first, minimalist, immutable developer OS.

## Usage

```bash
brew tap modib/forge
brew install ws-cli
```

## Formulae

| Formula | Description |
|---------|-------------|
| `ws-cli` | AI-native cross-project workspace manager |

## Updating

Formulae are automatically updated via CI when new releases are published.
